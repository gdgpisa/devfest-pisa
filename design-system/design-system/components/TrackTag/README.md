# TrackTag

Chip that names a session's track with a pastel fill and a dot in the track's core colour.

- Web `.dp-tag`, Mobile `.dp-tag--mobile`, Cloud `.dp-tag--cloud`, AI `.dp-tag--ai`.
- The consumer provides the track name as text; the word is required, colour alone never identifies a track.
- One tag per session. Do not invent new track colours; a fifth track uses the outline style of `Button`.
