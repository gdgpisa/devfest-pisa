# LocationLockup

The logo of the edition: the official DevFest location lockup, "DevFest" in the yellow braces with the white pill underneath, reading "Pisa".

- Everything except the word "Pisa" is the official file (`devfest-location-emptypill.png` in Logos, the kit's lockup with the placeholder text removed). Only "Pisa" is set, in Google Sans at regular weight, centred in the pill on the original baseline.
- For print and for anything Google reviews, export the same lockup from the kit's editable Google Drawings or .AI file with "Pisa" typed in the pill.
- Use it in the site header, on posters, badges and the opening slide. Minimum width 160px. Place it on `surface` or `surface-raised` only.
