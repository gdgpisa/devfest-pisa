# Button

Pill button with a 2px ink contour, in three variants.

- `.dp-btn`: the primary action on a page or slide (buy a ticket). One per view.
- `.dp-btn--outline`: secondary actions (see the agenda, read more).
- `.dp-btn--blue`: calls to the community (submit a talk, volunteer). Text stays `on-pastel`.

The consumer provides a `<button>` or `<a>` and the label. Labels are verbs in sentence case, two or three words, no emoji. Hover swaps fill and ink; focus shows the `focus` ring.
