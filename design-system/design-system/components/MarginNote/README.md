# MarginNote

A narrow annotation column beside running text, like the notes in a manuscript's margin.

- The consumer provides a short note (a year, a source, a line number, a link) and the paragraph it annotates.
- Note text is `code` in `ink-muted`; one key word may be `red-text`.
- Use on long pages (about, code of conduct, venue history), not on cards or slides. On phones the note moves above the paragraph.
