# Tag

Low-caps label on a tint, used for tracks and session types.

- Track colours: Web blue, Mobile green, Cloud yellow, AI red. Session types use `.lg-tag--neutral`.
- Text is the 80 stop of the tint's hue, so every tag passes 4.5:1. The word always names the track; colour is never the only signal.
- One tag per meaning; do not stack more than two on one item.
