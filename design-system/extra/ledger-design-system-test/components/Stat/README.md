# Stat

One number, its label and a note, separated from its neighbours by a hairline on top.

- The consumer provides a label (low caps), the value and a one-line note that gives the unit or the source.
- Values use tabular figures. Never invent a figure: if a number is not confirmed, leave the Stat out.
- Lay Stats in a row of three or four; never one alone.
- The edition count in the preview should be verified before publishing.
