# DevFest Pisa 2027 · design kit

- `design-system/`: the final design system. Start from `README.md` (brand book). `tokens.json` and `tokens.css` hold colours, type, spacing; `components/` has one folder per component with guidelines and a preview you can open in a browser; `assets/` has the official logo files.
- `site-mockups/`: the site mockups as plain HTML pages (open them in a browser; fonts load from Google Fonts). `01` is the current page with the two calls, `02` the full site with the 2026 sections. `explorations/` keeps the earlier versions.
- `extra/ledger-design-system-test/`: the second test system, kept for reference.
