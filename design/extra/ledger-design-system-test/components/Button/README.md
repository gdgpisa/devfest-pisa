# Button

Rectangular button with a small radius, in three weights.

- `.lg-btn`: the primary action, white text on `link` (4.96:1). One per view.
- `.lg-btn--secondary`: secondary actions, `text` on `surface` with a `border-strong` outline.
- `.lg-btn--ghost`: tertiary actions inside dense areas.

The consumer provides a `<button>` or `<a>` and a verb-first label in sentence case. Height is 40px; never stretch a button to full width on desktop.
