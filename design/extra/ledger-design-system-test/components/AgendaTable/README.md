# AgendaTable

The schedule as a table: times in tabular figures, one row per session.

- The consumer provides rows of time (24h), session title, speaker and role, one Tag, and room.
- Header row on `surface-sunken` with a `border-strong` rule; rows separated by `border` hairlines.
- On phones, wrap the table in a horizontally scrolling container rather than squeezing columns.
- Speaker names and titles in the preview are placeholders.
