# BarChart

Vertical bar chart drawn in one colour family, with the key bar highlighted and values labelled directly.

- The consumer provides a title that states the finding, the series (label and value) and a source line.
- Bars use `blue-30`; the one bar that matters uses `blue-60`. Gridlines in `border`, labels in `caption-12`.
- Label values above bars instead of relying on the axis. No legend for a single series.
- The preview plots the first ten Fibonacci numbers, which are exact, not sample data.
