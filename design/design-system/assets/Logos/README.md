Official DevFest logo files from the DevFest 2026 brand kit. The letters and braces are never redrawn or recoloured.

- `devfest-location-emptypill.png`: the official location lockup with the placeholder text removed from the pill. Base of the **LocationLockup** component, which writes "Pisa" in the pill.
- `devfest-location-nopill.png`: the lockup without the pill, kept from an earlier test; not used.
- `devfest-lockup-trim.png`: the braces lockup trimmed to its edges. Base of the **Badge** component.
- `devfest-lockup-location.png`: the untouched location lockup; the pill must read "Pisa" (make it from the kit's editable file). Use it where the standard mark is required.
- `devfest-lockup-braces.png`: braces only, for small spaces such as the site header on phones.
- `devfest-wordmark.png` and `devfest-wordmark-2026.png`: the horizontal wordmark with the GDG mark. The year version still reads 2026; replace it when the 2027 kit is out.

All files are dark ink on transparent: place them on `surface` or `surface-raised`, never on `ink` or a colour field.
