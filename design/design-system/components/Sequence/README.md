# Sequence

A band of Fibonacci terms in coloured squares, separated by commas or joined into one true equation: the system's signature, and the visual form of the motto candidate "1, 1, 2, 3, 5, DevFest".

- Two forms: the list `1, 1, 2, 3, 5, DevFest`, or a single equation such as `2 + 3 = 5`. Never chain equations (`1 + 1 = 2 + 3`): the arithmetic must be true.
- Use it once per layout: under the hero, as a slide footer, on a sticker, on a social teaser.
- `.dp-seq__term--next` is a dashed empty square with a red number: "the next number", for teasers and countdowns.
- Give the band an `aria-label` that reads the sequence aloud.
