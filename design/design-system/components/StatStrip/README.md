# StatStrip

One bordered row of big figures with a label each, used for audience numbers and for the venue distances.

- The consumer provides 3 or 4 items of value and label, plus a source line underneath when the figures describe a past edition.
- Values are real and sourced; never invent a figure. The preview shows the 2026 figures from the event site.
- On a `yellow` field keep labels in `ink`, not `ink-muted`.
