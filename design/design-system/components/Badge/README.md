# Badge

The official braces lockup set inside the golden rectangle, with "Pisa" in the blue 3-square and "2027" in the yellow 2-square.

- For social avatars, stickers, slide corners and lanyards. Set the unit with `--u` (default 40px; the badge is 8 × 5 units).
- The lockup is the official file (`devfest-lockup-trim.png` in Logos), untouched, in the bottom-right corner of the 5-square where the spiral never passes.
